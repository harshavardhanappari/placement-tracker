# placement-tracker

A responsive web application built using **HTML, CSS, and JavaScript** to help students manage and track their placement applications efficiently.

## 🚀 Live Demo

https://harshavardhanappari.github.io/placement-tracker/

---

## ✨ Features

### 📋 Application Management
- Add new company applications
- Edit existing applications
- Delete applications
- Prevent duplicate entries

### 📊 Placement Tracking
- Track Company Name
- Track Role
- Track Application Date
- Track Package (LPA)
- Add Personal Notes
- Track Application Status

### 🔍 Search & Filter
- Search applications by company name
- Filter applications based on status
- Quickly find important applications

### 📈 Dashboard Statistics
- Total Applications
- Selected Applications
- Rejected Applications
- Interview Applications
- Highest Package
- Average Package

### 💾 Data Persistence
- Uses Local Storage
- Data remains available even after refreshing the page

### 📱 Responsive Design
- Mobile Friendly
- Tablet Friendly
- Desktop Friendly
